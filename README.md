# SkillForge Proxy Checker

A lightweight open-source tool to test proxy health for web scraping projects.

Built for the SkillForge community to help developers quickly validate proxies.

### Features
- Checks if proxy is alive
- Measures latency (ms)
- Shows anonymous IP
- Multi-threaded for speed

### How to use
1. `pip install -r requirements.txt`
2. Add your proxies to `proxies.txt` (format ip:port)
3. Run: `python checker.py`

### Topic Relevance
This tool is relevant to SkillForge topics: proxies, web scraping, and anti-bot testing infrastructure.

Open-source and free for community use.
